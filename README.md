# Arcanum (Fabric 26.3 마법 모드)

비전의 지팡이와 마나 시스템을 추가하는 서버 사이드 중심 마법 모드입니다.

## 콘텐츠

| 아이템 | 설명 |
|---|---|
| 비전의 지팡이 (Arcane Wand) | 우클릭: 주문 시전 / 웅크리기 + 우클릭: 주문 변경 |
| 마나 수정 (Mana Crystal) | 우클릭하면 마나 35 회복 후 소모 |

| 주문 | 마나 | 쿨다운 | 효과 |
|---|---|---|---|
| 비전 화살 | 8 | 0.6초 | 시선 방향 최대 32칸 빔, 첫 대상에게 피해 8 + 넉백 |
| 서리 폭발 | 25 | 2초 | 반경 6칸 적에게 피해 5, 구속 III 5초, 빙결 |
| 점멸 | 15 | 1.5초 | 바라보는 방향으로 최대 12칸 순간이동 (벽에 막히면 가능한 곳까지) |
| 찬란한 치유 | 30 | 3초 | 반경 6칸 플레이어 체력 8 회복 + 재생 II, 언데드에게는 피해 10 |

- 마나 최대치 100, 약 0.3초마다 1씩 자동 회복 (가득 차는 데 약 30초)
- 마나와 선택한 주문은 플레이어에 저장되며 죽어도 유지됩니다
- 지팡이나 마나 수정을 들고 있으면 액션바에 현재 주문과 마나 게이지가 표시됩니다
- 주문은 플레이어, 시전자의 길들인 동물에게는 피해를 주지 않습니다

## 레시피

- 마나 수정 x2: 자수정 조각 + 청금석 (무형)
- 비전의 지팡이: 마나 수정 1개 + 블레이즈 막대 2개 (대각선 배치)

```
  C
 B
B
```

## 빌드

- Java 25, Gradle 9.x 필요 (Loom 1.17 기준)
- 공식 Fabric 예제 모드 템플릿의 `gradlew`를 복사하거나 `gradle wrapper`로 래퍼를 만든 뒤 실행하세요

```
./gradlew build
```

결과물은 `build/libs/arcanum-1.0.0.jar` 입니다. `mods` 폴더에 Fabric API와 함께 넣으면 됩니다.

## 구조

```
src/main/java/com/arcanum/
  ArcanumMod.java      진입점, 마나 회복 틱, 액션바 표시
  MagicData.java       마나/선택 주문 데이터 (어태치먼트)
  ModAttachments.java  어태치먼트 등록
  ModItems.java        아이템, 크리에이티브 탭 등록
  Spell.java           주문 목록 (비용, 쿨다운, 색상)
  Spells.java          주문 구현
  ArcaneWandItem.java  지팡이
  ManaCrystalItem.java 마나 수정
```

주문을 추가하려면 `Spell`에 항목을 하나 더하고 `Spells`에 구현 메서드를 만든 뒤 lang 파일에 이름을 추가하면 됩니다.
